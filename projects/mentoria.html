MentorIA

Sistema de Diagnóstico de Competências Académicas com Inteligência Artificial

Contexto e Desafio

O ensino superior em Moçambique, particularmente na Universidade Pedagógica de Maputo (UP-Maputo), enfrenta desafios relacionados com o elevado número de estudantes por turma. Muitas dificuldades de aprendizagem permanecem não identificadas a tempo, dificultando o acompanhamento individualizado.

Solução Desenvolvida

O MentorIA foi concebido como uma plataforma de apoio pedagógico baseada em Inteligência Artificial, permitindo aos docentes diagnosticar competências académicas e oferecer feedback personalizado aos estudantes. O sistema atua como assistente inteligente, realizando autoavaliações e simulando orientação individual do professor.

O Meu Papel

Participei no desenvolvimento da plataforma MentorIA, contribuindo para a implementação da API em ASP.NET Core, integração entre frontend e backend, autenticação de utilizadores e integração com a API da OpenAI para geração de feedback pedagógico inteligente. O projeto permitiu-me consolidar conhecimentos em desenvolvimento Full Stack, consumo de APIs, autenticação JWT e integração de serviços externos.

Principais Contribuições

  • Desenvolvimento da API REST utilizando ASP.NET Core.
  • Desenvolvimento da interface web em React.
  • Integração entre frontend e backend através de APIs REST.
  • Implementação de autenticação JWT e gestão de utilizadores.
  • Integração com a API da OpenAI.
  • Modelação da base de dados em SQL Server.
  • Testes e validação das funcionalidades.

Funcionalidades Principais

  • Gestão de disciplinas e módulos académicos
  • Definição de competências por disciplina
  • Criação de atividades de diagnóstico
  • Configuração de critérios de avaliação pelos docentes
  • Diagnóstico automático de competências
  • Feedback pedagógico personalizado baseado em IA
  • Identificação de pontos fortes e lacunas de aprendizagem
  • Recomendações de melhoria para estudantes

Tecnologias Utilizadas

ASP.NET Core Web API REST APIs React (Vite) OpenAI API SQL Server Entity Framework Core Autenticação JWT ASP.NET Identity Git
Impacto: O MentorIA foi desenvolvido como uma ferramenta de apoio ao processo de ensino-aprendizagem, permitindo automatizar diagnósticos de competências académicas e fornecer feedback personalizado através de Inteligência Artificial. O projeto proporcionou experiência prática no desenvolvimento de aplicações Full Stack, integração com APIs externas e implementação de soluções baseadas em IA.
